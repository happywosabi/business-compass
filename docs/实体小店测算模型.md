# 实体小店测算模型

> 状态：已确认
> 最后更新：2026-11-04
> 适用业态：餐饮、饮品、零售、美业、本地服务（共用一套门店模型）
> 所属功能：商业模式评估（见 [产品规划](产品规划.md) 4.1）

---

## 一、设计原则

- **按现金算，不按会计利润算**：小店主关心的是"钱够不够、什么时候赚回来"。折旧、摊销只在生成商业计划书的利润表时使用
- **每个参数三档**：悲观 / 中性 / 乐观
- **标注来源**：每个参数记录来源——用户填写 / AI 推断 / 行业默认值
- **用大白话提问**：专业指标由引擎内部换算
- **计算全部由代码完成**：AI 只负责提问、提取参数、解释结果

---

## 二、参数

### A. 启动投入（开业前一次性支出）

| 参数 | 大白话提问 | 能否收回 |
|---|---|---|
| 转让费 | 接手这个铺面要付转让费吗？多少？ | 否 |
| 装修 | 装修大概花多少？ | 否 |
| 设备 | 设备（厨具、机器、货架、收银等）花多少？ | 否 |
| 证照杂费 | 办证、设计、杂七杂八的费用 | 否 |
| 开业营销 | 开业活动、宣传准备花多少？ | 否 |
| 装修期房租 | 装修要几个月？房东给免租期吗？ | 否（= 装修月数 − 免租月数，最少为 0，乘以月租） |
| 房租押金 | 押几个月房租？ | 是 |
| 首批备货 | 第一批原料 / 货品花多少？ | 是（视为流动资金） |

```
不可收回投入 = 转让费 + 装修 + 设备 + 证照杂费 + 开业营销 + 装修期房租
可收回投入   = 房租押金 + 首批备货
启动投入     = 不可收回投入 + 可收回投入
```

### B. 收入

| 参数 | 符号 | 大白话提问 | 说明 |
|---|---|---|---|
| 日均单量 | N | 生意稳定后，一天大概能卖多少单 / 来多少客人？ | 全年平均水平；整个模型最敏感的参数，见第五节 |
| 客单价 | P | 平均每单 / 每位客人花多少钱？ | |
| 每月营业天数 | D | 一个月开几天？ | |
| 渠道结构 | — | 堂食、外卖、团购大概各占多少？ | 用于计算比例费率 f |
| 开业月份 | — | 打算几月开业？ | 用于对齐季节系数 |
| 爬坡系数 | ramp(t) | 一般不直接问，用业态默认值 | 默认第 1–4 个月为 50% / 65% / 80% / 90%，第 5 个月起 100% |
| 季节系数 | s(t) | 一般不直接问，用业态默认值 | 12 个月各一个值，**平均值为 1**（因此 N 代表全年平均水平） |

### C. 变动成本（卖得越多花得越多）

拆成两类。区分的原因：降价时按单成本不变，每单毛利会被压缩得更多，见第九节示例。

| 参数 | 符号 | 大白话提问 | 说明 |
|---|---|---|---|
| 按单成本 | c | 每单的原料、包装大概多少钱？ | 元 / 单 |
| 比例费率 | f | 一般不直接问，由渠道结构和平台费率算出 | 包括支付手续费、平台抽成、税费 |

```
f = Σ（渠道占比 × 该渠道费率） + 支付手续费率 + 综合税费率
```

- 综合税费率先作为一个参数，默认按小规模纳税人 / 个体工商户的优惠政策估算，以当地实际为准

### D. 固定成本（每月不管卖多少都要付）

| 参数 | 大白话提问 | 说明 |
|---|---|---|
| 房租（含物业） | 每月房租多少？ | |
| 租金递增 | 合同里房租每几年涨多少？ | 递增比例 g，递增周期 k 年 |
| 员工工资 | 请几个人？每人每月多少（含社保）？ | |
| 老板工资 | 你自己在店里干活吗？如果去打工，每月能挣多少？ | 不在店里干活则为 0。**必须计入**，否则用户会把自己的工资误当成利润 |
| 水电燃气 | 每月水电燃气大概多少？ | 第一版视为固定 |
| 其他固定支出 | 营销、维修、杂费 | |

```
每月固定成本 F(t) = 房租(t) + 员工工资 + 老板工资 + 水电燃气 + 其他固定支出
房租(t)          = 基础房租 × (1 + g) ^ floor((t − 1) ÷ (12 × k))
```

### E. 其他

| 参数 | 说明 |
|---|---|
| 租约期限 | 月数，用于回本检查 |
| 推演期限 | 默认 36 个月；计算回本时最多推演 120 个月 |

---

## 三、计算公式

### 3.1 单位经济

```
每单毛利 m = P × (1 − f) − c
```

### 3.2 逐月推演

月份 t 从开业当月 = 1 开始；装修期发生在 t = 1 之前，已计入启动投入。

```
第 t 月单量     N(t) = N × ramp(t) × s(t)
第 t 月现金流   π(t) = N(t) × D × m − F(t)

现金(0)  = − 启动投入
现金(t)  = 现金(t − 1) + π(t)
```

### 3.3 输出指标

| 指标 | 定义 |
|---|---|
| 稳定期月现金流 | ramp = 1、s = 1、基础房租时的 π；同时给出"不含老板工资"的版本 |
| 开始不亏钱的月份 | 第一个 π(t) ≥ 0 的月份 |
| 现金最低点 | min 现金(t)，t = 0 … 推演期限；同时记录出现在第几个月 |
| 建议准备资金 | \|现金最低点\| + 2 × F 到 \|现金最低点\| + 3 × F（2–3 个月固定成本作为安全垫） |
| 回本月份 | 最小的 t，使 Σ π(1…t) ≥ 不可收回投入。押金和备货可收回，不计入。120 个月内无法回本则输出"无法回本" |
| 租约检查 | 回本月份 > 租约期限 → 红灯 |
| 安全边际 | (N − N\*) ÷ N，即"客流再少百分之多少就开始亏" |

### 3.4 单变量临界值

按稳定期计算（ramp = 1、s = 1、基础房租），其他参数不变：

```
保本日单量     N*     = F ÷ (m × D)
保本客单价     P*     = (F ÷ (N × D) + c) ÷ (1 − f)
临界按单成本   c*     = P × (1 − f) − F ÷ (N × D)
临界房租       房租*  = N × D × m − (F − 房租)
```

## 四、约束与合理性检查

- **接待能力上限**：日均单量 ≤ 最大接待能力（座位数 × 每天可翻台次数 + 外卖出餐能力）。超出说明客流假设不现实
- **经验比例检查**：房租占营业额比例、人工占比、原料成本率、坪效、人效、爬坡期长短
- 具体阈值按业态整理，并注明数据来源（属于行业基准库）
- 偏离时给出提示，不拒绝计算

---

## 五、客流估算方法

日均单量最敏感，用户也最拿不准。用三种方法交叉验证，取偏保守的结果：

1. **选址法**：高峰时段门口每小时路过人数 × 进店率 × 成交率，换算到全天。用户可去门口蹲点数人——这也是"假设验证计划"的第一个实验
2. **对标法**：外卖平台上同商圈、同品类店铺显示的月销量，换算成日均单量
3. **产能反推**：座位数 × 翻台率。这是上限，不是预期

三种方法结果差距很大时，本身就是一条重要提醒。

## 六、不确定性处理

| 方法 | 版本 | 做法 | 输出 |
|---|---|---|---|
| 三种情景 | 第一版 | 参数全取悲观 / 全取中性 / 全取乐观 | 三条现金曲线。全悲观很少同时发生，只作为底线参考 |
| 敏感性分析 | 第一版 | 每次只让一个参数取悲观值 / 乐观值，其他保持中性 | 按对"第 36 个月末手里的钱"的影响排序（悲观时下降最多的排最前），得出"最怕的 3 个变量"；同时给出回本月份的变化 |
| 蒙特卡洛模拟 | 第二版 | 每个参数按三档值生成三角分布，随机模拟一万次 | 盈利概率、回本月份分布、"准备 X 万有 90% 把握撑过爬坡期" |

蒙特卡洛第一版假设参数互相独立；现实中客流和客单价可能相关（如降价带来更多客人），以后再细化。

## 七、给用户的结果

报告结构：
1. 一句话结论
2. 要准备多少钱
3. 第几个月开始不亏钱、第几个月回本（含 / 不含老板工资）
4. 每天至少卖多少、客单价不能低于多少
5. 最怕的 3 个变量及其临界值
6. 合理性提醒
7. 建议的验证实验
8. 哪些数字是用户填的、哪些是默认值

示例话术：
> 按你目前的估计，这家店需要准备约 35 万元。开业后第 3 个月开始不亏钱，第 21 个月收回投入（已算上你自己每月 6000 元的工资）。
> 最需要注意：客单价不能低于 12.6 元，每天至少要卖 147 杯。如果客流比你估计的少两成，3 年租约内回不了本。
> 开店前建议先做一件事：工作日和周末各挑一个高峰时段，去门口数一数路过的人。

## 八、模型边界

- **不纳入数字计算**：竞争对手开到隔壁、政策变化、老板个人能力——放在单独的定性评分里
- **转让费回收**：租约到期转出时可能收回部分转让费，模型不计算，结果偏保守
- **准确度取决于输入**，尤其是客流。报告中始终标明参数来源

## 九、示例与测试用例：奶茶店

> 数字为虚构，仅用于演示和测试。以下结果已用脚本核对，可作为计算引擎的第一个测试用例。

### 9.1 输入

| 参数 | 数值 |
|---|---|
| 客单价 P | 15 元 |
| 稳定期日均单量 N | 200 单 |
| 每月营业天数 D | 30 天 |
| 按单成本 c | 5.4 元 |
| 比例费率 f | 8% |
| 房租 | 12,000 元 / 月，不递增 |
| 员工工资 | 3 人，合计 15,000 元 / 月 |
| 水电杂费 | 4,000 元 / 月 |
| 老板工资 | 6,000 元 / 月 |
| 每月固定成本 F | 37,000 元（不含老板工资 31,000 元） |
| 不可收回投入 | 转让费 50,000 + 装修 80,000 + 设备 60,000 + 证照 5,000 + 开业营销 10,000 + 装修期房租 12,000 = 217,000 元 |
| 可收回投入 | 押金 24,000 + 首批备货 10,000 = 34,000 元 |
| 爬坡系数 | 50% / 65% / 80% / 90% / 之后 100% |
| 季节系数 | 全部为 1 |
| 租约期限 | 36 个月 |

### 9.2 预期输出

| 指标 | 预期值 |
|---|---|
| 每单毛利 m | 8.4 元 |
| 稳定期月现金流 | 13,400 元（不含老板工资 19,400 元） |
| 开始不亏钱的月份 | 第 3 个月（不含老板工资：第 2 个月） |
| 保本日单量 N\* | 146.83 → 147 单 |
| 安全边际 | 26.6% |
| 保本客单价 P\* | 12.57 元（−16.2%） |
| 临界按单成本 c\* | 7.63 元（+41.4%） |
| 临界房租 | 25,400 元（+111.7%） |
| 现金最低点 | −267,040 元，第 2 个月 |
| 建议准备资金 | 341,040 – 378,040 元 |
| 回本月份 | 第 21 个月（不含老板工资：第 15 个月） |
| 租约检查 | 通过（21 ≤ 36） |

### 9.3 逐月现金（含老板工资）

| 月份 t | π(t) | 现金(t) |
|---|---|---|
| 0 | — | −251,000 |
| 1 | −11,800 | −262,800 |
| 2 | −4,240 | −267,040 |
| 3 | 3,320 | −263,720 |
| 4 | 8,360 | −255,360 |
| 5 | 13,400 | −241,960 |

### 9.4 情景：客流比预期少 20%（N = 160）

| 指标 | 预期值 |
|---|---|
| 稳定期月现金流 | 3,320 元 |
| 现金最低点 | −284,088 元，第 4 个月 |
| 回本月份 | 第 80 个月 |
| 租约检查 | **红灯**（80 > 36） |

### 9.5 结论解读

- 这家店最怕降价，其次怕客流不足，房租不是主要风险
- 降价比少来客人更伤：降价时按单成本不变，每单毛利被压缩得更多。"靠打折引流"对这家店很危险

### 引擎 1.0.1 的资金期限约定（2026-11-05）

结果中的现金低点与建议准备资金取开业前及前 36 个月；120 个月推演仅用于寻找回本月份。这样准备资金与页面现金曲线使用同一个期限。资金建议不代表第 36 个月以后一定安全，租金递增等长期风险仍需核实。回本判定覆盖不可收回投入，曲线参考线为 `-startup.recoverable`。
