## 日常操作与回退

```bash
ssh root@8.129.226.231
cd /opt/business-compass/current
export COMPOSE_FILE=compose.yaml:compose.existing-proxy.yaml
docker compose ps
docker compose logs --tail 100 api
bash deploy/scripts/backup.sh /opt/business-compass/backups/新的文件名.dump
bash deploy/scripts/verify-backup.sh /opt/business-compass/backups/新的文件名.dump
```

更新前备份数据库，使用新版本目录及镜像标签，核对端口、网段和资源余量，再执行 `docker compose up -d --no-build --pull never`。Nginx记录API容器地址，API重建后需仅对本项目执行 `docker compose restart nginx` 并检查健康。

停用本项目可执行上述目录中的 `docker compose stop`，不会停止其他项目；保留数据库卷。撤销公网入口时，只移除本项目import与站点文件，验证Caddy配置后reload。原配置备份在 `backups/Caddyfile.before-shop-20261106`；若此后其他站点有更新，不要整份覆盖该备份。不要执行全局清理、Docker重启或 `down -v`。
