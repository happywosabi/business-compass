# 水果零售店测算模型

> 已实现，2026-11-06。入口：实体小店 → 水果店（零售）。

## 档案范围

整店经营预测，支持想法、筹备、经营中；与果园供应商独立。不做单果库存流水、历史利润台账或历史回本。复用 `physical_store`，业态 `fruit_retail`，参数 `schema_version=3`；已有饮品与果园数据保留原结构。

基础资料沿用店名、城市、经营阶段；补充位置、面积、销售渠道。财务输入、公开商品资料分开保存。没有已核实的行业默认值，费用为零也需用户明确确认。

## 收入与成本口径

收入二选一，切换时清空另一组：

- 原始日/月营业额及每月营业天数；日营业额×营业天数＝月营业额。
- 日均交易笔数×每笔客单价×营业天数。元/斤、元/kg、元/盒属于商品售价，不等于客单价。

采购成本二选一：

- 未损耗毛利率 `g`＋按采购成本加权损耗率 `l`：含损耗采购成本率 `c=(1-g)/(1-l)`。
- 综合采购成本率 `c`：已经包含损耗，不再扣损耗；允许超过100%以表达倒挂亏损。

毛利率以销售额为分母，不同于按进价计算的加价率。100%损耗不能形成持续销售，服务拒绝。实物重量损耗不能直接代替采购成本加权损耗。月采购付款受库存增减影响，不等于销售对应采购成本。

月销售贡献＝营业额×（1－c－包装率－渠道费用率－支付税费率）。扣房租、已付人工、老板报酬、水电（含冷柜）、固定配送及其他固定费用后得到月结余；同时展示未扣老板报酬值。销售贡献率为正时，固定成本÷贡献率＝保本月营业额，再除营业天数得到保本日营业额。否则保本值为空。

## 库存与资金

参考备货资金＝月采购成本÷营业天数×备货天数。库存金额按进货成本填写；缺口＝max（参考备货－库存，0）。库存是资金占用，不再作为月费用重复扣。

筹备启动投入＝装修＋冷柜/货架/秤等设备＋押金＋首批库存；本次所需资金＝启动投入＋备货缺口。正月结余下预测回本，最多推演120个月；这不是持续亏损时的总资金保证。

经营中历史装修/设备/押金仅记录，不重复扣；仅新增备货缺口需要现金，不假设超额库存原价变现，不计算历史回本。可用现金未知时不推断即时现金缺口或可用期；已知时扣本次资金需求，亏损时计算剩余现金可维持月数。

## 快照、试算与访谈

从北京时间测算日期起预测未来36个月，现销、采购即付、库存稳定；无默认爬坡和季节系数。快照保存阶段、日期、输入与结果，之后档案修改不影响历史。阶段改变后需重新测算，再应用该阶段的试算。

三档收入/毛利悲观较低，费用/损耗悲观较高；未填范围等同中性。敏感性一次只变一个字段，试算可改变备货天数、房租等，确认后生成新快照。

访谈每轮最多两问。原始周期金额交代码换算；日薪先确认支付天数与实际付薪人数，老板报酬单列。零售价不记录为客单价。公开商品、售价单位、已确认产地、配送与活动用于文案，内部财务不传入营销模型；未知事实最多3个具体待填项。

## 固定验收案例

月销售90,000元、毛利30%、损耗10%、营业30天、备货3天 → 采购70,000元、参考库存7,000元。等价综合采购成本率7/9。首批库存4,000元时补足3,000元；经营中库存10,000元时不产生负资金需求。
