# 热点关联与联网检索

内容创作先选择日常/供货切入点，再在下方「关联一个热点」选择可选热点。门店与果园分别展示相关候选；不选择时保留原来的写作流程。选择后可查看摘要、媒体和时间，生成时重新检索该标题，将实际取得的背景与切入点共同交给 DeepSeek。

## 来源与时效

- 默认在线来源为固定 HTTPS RSS：中新网生活、财经、即时频道和食品伙伴网。按饮品、咖啡、果品等关键词筛选近期报道，无需额外搜索密钥；不宣称全国热搜或小红书热榜排名。2026-11-07 生产实测必应资讯先跳转中国站再跳首页，已移除对该端点的依赖。
- 仅收录有发布时间、近 7 天的报道；候选采集记录超过 24 小时不再展示或接受新生成请求。默认来源按发布时间排列，排名不表示热度。
- worker 默认每两小时更新；页面只读取缓存，「刷新列表」也不触发付费采集，不消耗个人 AI 次数。所有 worker 共用数据库 advisory lock、24小时滚动公共上限 `HOT_DAILY_LIMIT=24`、最短间隔 `HOT_MIN_INTERVAL_SECONDS=3600` 和总时限 `HOT_RUN_SECONDS=90`；失败和空结果也计次、占冷却，`force` 不能绕过。
- `CONTENT_NEWS_ENABLED=false` 可关闭默认候选资讯采集；`HOTAPI_BASE_URL` 可另外接入运维配置的自部署 DailyHotApi（最多8个频道），不接受用户或模型指定地址。后者仅提供标题时明确记录为标题来源。单个来源失败不影响其他来源；全部失败才标记失败，来源正常但无合适候选则成功且不调用模型。
- 候选经过词过滤、DeepSeek 营销适用性审核及去重；并非人工审稿。没有适合候选时显示空状态，不补造热点。
- `hot_collection_runs` 保存开始/结束、模型、状态、调用次数及收到的 LLM/Embedding token 用量；`diagnostics` 仅存固定阶段/来源/错误代码、HTTP状态、条数和候选计数，后台可展开查看，不记录上游正文、URL、凭据或原始异常文本。旧记录不能反推具体阶段。分类单次最多1000输出token且禁用自动重试，返回值必须是有限的整数索引数组；失败不发布候选。未返回usage不代表零费用。

## DeepSeek 的实际联网方式

核对官方 [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion) 与 [Tool Calls](https://api-docs.deepseek.com/guides/tool_calls) 文档：当前 API 支持函数工具，没有网页端同款的内置联网开关。本项目由服务端执行真实资讯检索，再将结果注入 DeepSeek 写作上下文；没有发送虚构的 `enable_search` 参数，也不声称模型读取了新闻全文。

生成任务保存 `hot_research` 和来源快照，页面在「这份草稿的依据」展示：

- `live`：本次联网取得与所选标题相关的摘要。
- `cached`：本次未获得新资料，使用选中时已有摘要并保留时间。
- `title_only`：未取得详情且原来源仅有标题，只围绕标题话题关联。

抓取端点固定，不跟随重定向、不抓取文章链接、不继承代理环境和 netrc 凭据；每个来源最多1MB、15秒总时限，拒绝压缩响应放大和非RSS格式。使用 defusedxml 拒绝 DTD、实体与外部引用（含UTF-16），过滤无效/内网/带凭据的展示链接。仅收录近7天有效日期，食品伙伴网无时区时间按北京时间解释。生成前从这些固定RSS重新匹配标题，找不到时沿用带时间的来源快照。

来源文本作为不可信参考资料，不能覆盖系统指令；灾难、医疗功效、食品安全风险及监管整治等内容不用于营销。其他地区天气、品牌商品与活动不能视为本店事实，未知经营信息继续使用最多三处具体待填项。果园内部财务参数不发送给营销模型。

真实门店/果园生成记录见 `热点关联回归样例.json`，包含本次实际摘要、媒体、发布时间与检索时间，不含账户和会话信息。浏览器在1440、1000、390像素完成选择、生成、来源恢复；失败/空状态通过受控接口响应另行验证。
