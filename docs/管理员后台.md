# 管理员后台实施与运维

## 范围与入口

同站点 `/admin`，普通账号无入口、无接口访问权。使用普通登录后再次验证密码，当前会话解锁固定 15 分钟；锁定、退出、改密、重置密码、撤销会话或管理员身份后失效。首期只有 `is_admin` 角色，不提供网页授权入口。

| 页面 | 已实现能力 |
| --- | --- |
| 运行概览 | 用户、有效档案、测算预约、AI 状态/成功率/tokens，7/30 天北京时间趋势，公共热点独立统计 |
| 用户管理 | 邮箱/昵称/状态/验证筛选，注册/登录时间、档案及存储使用量；停用/启用/解锁/撤销全部会话/日额度 0–1000 或系统默认 |
| AI 任务 | 用户、模型、种类、状态、日期筛选；耗时、tokens、脱敏错误、取消；保留用量 |
| 档案诊断 | 摘要分页，填写原因后只读查看参数、历史、测算、用户可见对话、报告和文案 |
| 热点来源 | 自动审核及过期状态、独立人工下架；采集刷新不覆盖下架标记，恢复仍受审核/时效限制 |
| 操作审计 | 操作人/对象/类型/结果筛选，原因、IP、时间、前后状态；保留 180 天，无网页修改/删除接口 |
| 系统状态 | 数据库、应用版本、模型名、凭据配置布尔值、worker 心跳及最近采集；心跳间隔 60 秒，180 秒过期 |

列表默认 20 条，最多 100 条，以时间和 UUID 游标排序。后台响应包含 `Cache-Control: no-store`；敏感查询用 POST 原因，写入校验同源 Origin 和 JSON。资料仅保存在页面内存，锁定/退出清空。审计不包含密码、令牌、模型提示词、内部思考或用户正文。管理写入与成功审计同事务，状态变更先锁定并核对旧值；停用不能作用于自身且保护最后一个可用管理员。AI 写入前重新锁定并检查账号和任务。

## 首位管理员

先正常注册并验证邮箱。运维人员在服务器运行（将 `EMAIL` 替换为明确指定的邮箱）：

```bash
cd /opt/business-compass/current
docker compose exec -T api python -m app.admin.cli grant EMAIL --reason '运营方指定首位管理员'
# 撤销：必须保留另一个已验证、启用的管理员
# docker compose exec -T api python -m app.admin.cli revoke EMAIL --reason '调整管理员职责'
```

授权和撤销都会清除目标全部登录会话并记录审计；重新登录后从“我的 → 管理工作台”进入。没有预设账号或密码。运维记录不保存账号密码。

## 资源边界与 AI 确认

- 未验证/已验证账号最多 10/100 份档案（含回收站），存储 10/100 MiB；数据库触发器按业务行 JSONB UTF-8 字节维护事务账本，含参数历史、快照、对话、AI 结果及确认记录。硬删除释放占用，软删除计数保留；已有超额资料保留，可读取、删除及缩减，限制新增占用。
- 档案最多 256 KiB；备注 1000 字，价值主张 20 字段、每字段 2000 字，集合和文本有边界；创建/复制/编辑共用默认 30 次/分钟、300 次/天预算，代理另按 IP 限流。
- 模型消息和工具合计最大 128 KiB；个人每日输入 8 MiB，重试重复计入。仅裁剪完整旧轮次，保留工具配对、系统规则及当前状态，必需内容超限时拒绝。
- 访谈中的默认值、正式测算、试算应用只生成确认卡片；按钮绑定用户、档案、revision、动作及载荷，有效 10 分钟，重复确认返回已有结果，过期或修订变化返回 409。手工测算按钮仍可用；完整计算统一经过进程隔离和预算。
